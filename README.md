# Agentry

> Playwright for AI Agents — end-to-end testing for skills, plugins, LLM gateways, and MCP gateways via automated AI agents.

Agentry drives real AI agents (Claude, Codex, Gemini) through scripted scenarios so you can write
deterministic-ish e2e tests against the things agents interact with: skills, plugins, LLM gateways,
and MCP gateways.

> **Status:** Early development. Specs are being refined — see `docs/` (coming soon).
